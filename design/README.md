# 界面设计

现在的界面风格是 M9 定下的"纸墨"。样稿是 `mockups-m9/index.html`，用浏览器直接打开就能看（不联网，不用启动服务），可以切换浅色和深色。正式代码里的颜色、字号、间距都在 `src/styles/tokens.css`，规则见 `docs/architecture.md` 的"界面"一节。

- 偏暖的纸白底加很淡的纸纹，墨色几级灰；深色是近黑的底、米白的墨。除了出错和删除用的一点暗红，没有别的颜色
- 没有卡片：整个窗口是一张纸，详情直接铺在纸上
- 分区用细线，细线两头留白、互不相连
- 选中项左边一道墨色短竖线；输入框是下划线，正在输入的加深；毛玻璃只用在输入框和快速搜索框上
- 大标题的英文用 Palatino 衬线，中文仍是微软雅黑

`icons/` 是 69 个 KeePass 标准图标的预览页，由 `tools/icon-sheet.mjs` 生成。

M1 的三套样稿（Windows 原生、键帽、蓝染）和 M9 挑选时的四套方向已经删掉，需要时在 git 历史里找（tag `m8` 及以前）。
