# 界面风格样稿（M1）

三套风格用同一份假数据，每套都有主窗口、快速搜索、解锁三个页面，浅色和深色各一版。用浏览器直接打开 `mockups/index.html` 就能看，不需要联网，也不用启动服务。

| 风格 | 一句话 | 字体 | 代价 |
|---|---|---|---|
| A 原生 | 像 Windows 11 自带的应用：云母背景、系统强调色 | Segoe UI Variable + 微软雅黑（系统自带） | 个性最弱，快捷键只在悬停和提示里出现 |
| B 键帽 | 每个可复制字段旁是对应的键帽，点它和按键效果一样；表格式列表，底部常驻快捷键栏 | Bahnschrift + 微软雅黑；密码和验证码用 Cascadia Mono（都是系统自带） | 信息密度高，第一眼偏"工具" |
| C 蓝染 | 靛蓝染布做底色，缝线做分隔，留白多，标题用宋体 | 等线 + 思源宋体（标题）；Cascadia Mono（密码） | 思源宋体要随程序打包，安装包大 8–10 MB；不打包就退回微软雅黑，标题会失去特点 |

样稿里的交互：点击、方向键选条目，Ctrl+B / C / T 复制（会弹出"10 秒后清除剪贴板"的提示），Ctrl+H 显示密码，Ctrl+F 搜索，Ctrl+L 锁定，解锁页随便输个密码按 Enter 就回到主窗口。

几条三套共用的约定，选定风格后照搬到正式代码：

- 密码隐藏时一律显示 12 个点，不暴露真实长度
- 列表默认按修改时间倒序
- 快速搜索按"标题开头 > 标题包含 > 用户名 > 网址"排序；没输入时显示最近使用的条目
- 复制密码和验证码的提示带 10 秒倒计时条，和清空剪贴板的时间一致

选定之后，颜色、字号、间距会整理成设计变量，放进正式工程。
