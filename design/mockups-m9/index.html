纸墨

在 D 纸墨上调整：详情不再是实心卡片，直接铺在纸上；分区靠互不相连的细线；只用墨色，没有铅笔笔触。

外观

纸和细线整个窗口是一张纸，没有卡片。分区的细线两头都留白，彼此不相连：三栏之间的竖线不到顶也不到底，列表和详情里的横线不碰到竖线，标题栏下面不画线。

状态用普通的线选中项左边一道墨色短竖线；正在输入的那一栏下划线加深；验证码倒计时是细线圆环；密码强度是五小段横条。

只有墨色浅色是纸白底、近黑的墨，深色是近黑的底、米白的墨，中间几级灰。整个界面没有彩色；只有出错、删除这类提示用一点暗红。

字体用 Windows 自带的 Segoe UI 和微软雅黑；标题的英文是 Palatino 衬线，中文仍是微软雅黑（Windows 没有好看的中文衬线字体）。图里的条目都是演示数据。
